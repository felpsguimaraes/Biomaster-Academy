# Proposta comercial — Biomáster Academy (separada da plataforma)

- `propuesta-comercial.pdf` / `.html` — documento para apresentar à professora (espanhol). O HTML tem calculadora interativa.
- `build.py` — gera o HTML a partir dos **supuestos** (preços, comissões, minutos). Edite os valores no topo e rode `python3 proposta/build.py`; depois exporte o PDF abrindo o HTML no Chrome (Imprimir → Salvar como PDF).
- `legal/` — **rascunhos** (revisar por advogado): Termos e Condições, Política de Privacidade, Contrato desenvolvedor–titular (opções A/B/C).

Os valores de comissão e de várias tarifas vêm de fontes secundárias: confirmar com cada provedor antes de apresentar.

- `analisis-hotmart.html` — ferramenta (100% no navegador) para a professora medir a comissão efetiva real da Hotmart a partir do relatório de vendas (CSV) ou estimar com números próprios.
